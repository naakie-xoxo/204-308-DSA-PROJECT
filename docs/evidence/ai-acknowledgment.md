# AI Acknowledgment

Generative AI tools were used as a supporting development aid during this project.

AI assistance was used primarily to help organise the initial Maven project and file structure, establish the GitHub repository as a collaborative workspace for the team, clarify Git and GitHub workflows, and assist with troubleshooting build and integration issues.

AI was also used mainly as a verification and review aid. This included checking implementations against the project brief, reviewing pull requests, compiler errors and test failures, identifying edge cases or integration problems, suggesting targeted corrections, and helping verify that the algorithms, custom data structures, database integration, tests, trace evidence and empirical results were consistent with the project requirements.

AI assistance was additionally used to help organise and refine technical documentation and reviewer-response evidence.

The team remained responsible for implementing the project, reviewing proposed changes, running and interpreting tests, integrating and merging code, understanding the algorithms and data structures, and preparing to defend the work during the oral presentation.

AI-generated suggestions were not accepted automatically. Proposed changes were checked against the repository, test results and project specification before being incorporated.
